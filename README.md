One word for the human this agent works for: Relentless. He never
lets up — every task is "maksimalkan", every delay gets cursed, and
a slow agent gets swapped mid-sentence. One word covers all of it.

## Run it

```sh
python3 main.py
```

Writes the single word to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`). Pure standard library, deterministic:
two runs produce byte-identical output.
